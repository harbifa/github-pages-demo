Behind the pages

About This Demo

A beginner-friendly project that shows how a few ordinary files can become a complete website. No installation or build step required.

HTML

Three connected pages

Each page has its own content and the same navigation, so you can explore the whole site.

CSS

One shared stylesheet

css/style.css sets the layout, typography, and theme colors for every page.

JAVASCRIPT + SVG

Small files, useful details

js/script.js powers the theme button. images/logo.svg supplies the local logo.

Why relative paths?

Links such as about.html and images/logo.svg stay relative to the page, whether you open it locally or inside a repository path.
